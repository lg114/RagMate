          Advanced Architecture & Retrieval Specs

          The retrieval pipeline is frozen and verified against the deterministic evaluation baseline.

          Chunking: title_path with Small-to-Big parent expansion (parent 2500 chars, child 1000 chars).
          Hybrid Search: BM25 text rank fused with 1024-dim HNSW vector search via Reciprocal Rank Fusion (k=60).
          Re-ranking: Top 30 candidates re-scored via BAAI/bge-reranker-v2-m3; scores < 0.3 filtered out; dynamic top 15 retained.
          Grounding: Automatically hedges or refuses when retrieved passage evidence is insufficient.
          LangSmith Tracing Telemetry Transmit retrieval spans and LLM call traces to LangSmith platform.
